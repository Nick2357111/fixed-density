1. 模型与参数

k = F(ρ) · (γ_rel·S_rel + γ_jack·S_jack + γ_cross·S_cross + γ_hold·S_hold)  （ln 倍率，无常数项）
F(ρ) = lin · ρ + (1 - lin) · (1 + ch) · ρh / (ρh + ch)  （在线性 toe 与 Hill 型饱和之间混合：低 ρ 近似线性、高 ρ 趋平）
n_LN = k · n_rc  （RC 求得的 n 直接按倍率缩放）
ln_value = a · ln(b · n_LN + 1)  （含下界对数标定，即变换后的值）
g_ln(value) ≈ ln_value  （value 变换曲线，仿 RC 的 g：softplus 分段、两端线性渐近、严格单调）
当前：γ_rel = 0.1，γ_jack = 0.4，γ_cross = 0，γ_hold = 0.2， h = 6，c = 0.33，lin = 0.1，a = 5.4420，b = 0.09604
变换曲线：σ = [2.5, 0.799, 0.2, 1.013, 1.194, 0.2, 1.259]，衔接点 [(1.5, 1.0), (3.5, 1.2), (6.0, 1.5), (9.5, 1.2), (13.0, 1.0), (15.5, 1.0)]，拟合范围 [1, 17.5]， 斜率界 [0.2, 2.5]
两侧 R²：变换后口径 0.9625 / 原始口径 0.9509 （拟合集 N = 102，含段位单曲 64 张）

ρ = 长条占比（长条物件数 / 物件总数）；
S_rel（抓准）= 全谱 LN 松手事件“相邻松手间距倒数”的均值；
S_jack（控手）= 全谱 LN 松手事件“松手→同轨下一次按下间距倒数”的均值；
S_cross（跨轨）= 全谱 LN 松手事件“超出本地基线期望的跨轨动作速率”的均值；
S_hold（保持时长）= 保持时长 / 该轨物件平均间隔 的均值（无量纲，一根长条跨越多少个本地节拍）。
长度因子 h = ℓ/(ℓ+ℓ₀)（ℓ₀ = 40ms）：S_rel / S_jack 逐根再乘 h，恢复“有效长条中 越长越难”的单调性——纯长度门会把这条信息整段削掉。ℓ₀ ≤ 0 时关闭。
松手吸收折扣 λ = 0.25：roll 反键里 LN 头挨得很近，松手时刻距邻近起音不足 半个本地节拍时，OD9 判定窗下可直接按两头中点打（当成高密度米），不需要独立控制； 此时该次松手对 S_rel / S_jack 的贡献按 w = 1 - λ·a 打折（a∈[0,1] 为吸收度）。
时长有效性门 v = smoothstep(ℓ_med; lo, hi)（ms）：lo = 20 + 0.4·(W_head+W_tail)， hi = 1.3·lo，其中 W_head = (64-3·OD)/2、W_tail = 1.5·W_head（LN 尾判为 1.5 倍判定）。 长条时长中位数过短的谱面（roll 反键 / 高速 LN 流，判定上等同单键）整层结构量清零， 四个 S 同乘 v。OD8 时门为 [45, 49.5]ms、OD0 时 [60, 66]ms。
各项 S 只描述“每根 LN 有多强”，无 LN 时 ρ = 0 且各项皆 0 ⇒ k = 0 ⇒ n_LN = 0 ⇒ ln_value = 0， 即“几乎没有 ln 的谱面显示 0”。
F(ρ) 用 Hill 型而非幂律 ρm：幂律在高 ρ 区仍在快速变化，而 LN 谱残差与 ρ 正相关 （响应偏强）；Hill 型高 ρ 趋平、低 ρ 陡降，可同时改善 LN 拟合与压低非 LN 谱尾部 （实测 h=4,c=0.4：LN RMSE 1.002→0.884，非 LN 谱最大 7.95→0.63）。
纯 Hill 在 ρ ≪ c 时按 ρh 塌向 0（h=6 时 ρ=1% 的 F 仅 1e-11）， 实战中“长条占比很小但确有 LN 难度”的谱面会被直接归零，故叠一条线性 toe （lin = 0.1）：低 ρ 段近似线性（斜率 lin），仍保留 ρ 落在 非 LN 谱 max≈0.14 与 LN 谱 min≈0.25 之间时的陡峭过渡。实测 lin=0.10 时 LN RMSE 与纯 Hill 持平，lin=0.20 才略升（代价见报告末尾参数说明）。
S_hold 用“相对本地节拍”而非 1000/ℓ：后者会被搜索归零（又是密度代理）， 前者使 LN RMSE 0.884→0.864 且三个特征桶同时改善。 a、b 由下方 LN 谱面最小二乘拟合（给定 b 时 a 有闭式解）。
双口径（与 RC 报告一致）：变换后口径直接比较 ln_value 与 g_ln(value)； 原始口径把 ln_value 经 g_ln-1 反解回 value 再与实际 value 比较， 正文的 RMSE / 等级 / 分桶统计均以原始口径为准。
